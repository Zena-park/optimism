## 🎯 핵심 기여

### 1. 옵티미스틱 롤업의 근본적 취약성 규명
- **인센티브 부정합성**: 경제적 인센티브와 기대 행동의 불일치 증명
- **게임이론적 분석**: 합리적 참여자의 실제 행동이 시스템 보안을 약화시킬 수 있음을 수학적으로 입증
- **보안 모델의 재검토**: 기존 옵티미스틱 롤업 보안 가정의 오류 지적

### 2. 실증적 공격 시나리오 제시
- **현실적 위협**: 이론적 취약점을 실제 공격으로 연결
- **경제적 손실 사례**: 3억 2600만 달러 브릿지 공격 사례 분석
- **시스템적 리스크**: 개별 취약점이 전체 생태계에 미치는 파급효과

```
├── 검색 비용 (Search Costs)
│   ├── 모든 트랜잭션 검증의 높은 비용
│   ├── 시간과 컴퓨팅 자원 소모
│   └── 검증자의 경제적 부담
├── 낮은 탐지 확률
│   ├── 부정행위 발견 가능성 희박
│   ├── 투입 대비 낮은 성공률
│   └── 기대 수익 < 투입 비용
└── 잘못된 도전의 페널티
    ├── 오탐 시 경제적 손실
    ├── 확신 부족 시 행동 회피
    └── 소극적 검증 행태 유발
```

## 📊 게임이론적 분석

### 검증자 행동 모델
```
Validator Behavior Strategies:
├── 탐색 안 함 (No Search): b 확률
│   ├── 검증 비용 회피
│   ├── 무임승차 유인
│   └── 단기적 이익 추구
├── 맹목적 도전 (Blind Challenge): g 확률  
│   ├── 무작위 도전 시도
│   ├── 증거 없는 추측
│   └── 비효율적 자원 사용
└── 정직한 검증 (Honest Verification): h 확률
    ├── 철저한 검증 수행
    ├── 증거 기반 도전
    └── 높은 비용과 노력
```

### 균형점 분석
```
Mathematical Equilibrium:
Mixed Strategy Equilibrium ≠ Pure Honest Equilibrium

조건:
├── Search Cost > Expected Reward
├── Challenge Penalty > Potential Gain  
├── Detection Probability < Critical Threshold
└── 결과: 정직하지 않은 균형점 존재
```

## 📈 수학적 모델링

### 검증자 유틸리티 함수
```
Utility Analysis:
U_validator = P(find_fraud) × Reward - Search_Cost - P(wrong_challenge) × Penalty

Current Problem:
├── P(find_fraud) ≈ 0 (매우 낮음)
├── Search_Cost >> 0 (상당한 비용)
├── P(wrong_challenge) > 0 (오탐 위험)
└── Penalty > 0 (잘못된 도전 비용)

Result: U_validator < 0 (부정적 기대효용)
```

### 균형점 조건
```
Equilibrium Conditions:
For Honest Behavior:
├── Expected_Reward ≥ Search_Cost
├── Detection_Probability ≥ Critical_Threshold  
├── False_Positive_Penalty ≤ Acceptable_Risk
└── Long_term_Incentive > Short_term_Cost
```
